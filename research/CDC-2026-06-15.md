## 3. Trailing Offset computation

- Baseline (tight posture): `2.0 × ATR% = 2.0 × 2.98% = 5.95%`
- Adjustments applied: widened from 5.95% to 7.5%.
- Reason for each adjustment: CDC is among the thinnest names on the board (turnover often
  ₱2k–₱55k/day) and prices in coarse ₱0.01 ticks — one tick alone is **1.67%** at ₱0.60, and a
  routine intraday range already reaches ~6.7% (Jun 11: ₱0.59–0.63 = 4 ticks). A 5.95% offset is
  only ~3.5 ticks and would be whipsawed by ordinary tick noise, so it is widened to ~4.5 ticks.
  The low computed ATR% understates real risk because the stock is near-frozen between gaps;
  widening compensates. Still well inside the ~12.5% soft ceiling.
- Rounding: `5.95% → ` **`7.5%`** (after illiquidity/tick widening, rounded to nearest 0.5)
- **Trailing Offset = 7.5%**

## 4. Limit Price (execution buffer) computation

- Baseline: `Trailing Offset ÷ 5 = 7.5 ÷ 5 = 1.50%`
- Adjustments applied: widened from 1.50% to 3.5%.
- Reason for each adjustment: at ₱0.60 one PSE tick (₱0.01) is **1.67%**, so a 1.5% buffer is
  *less than a single tick* and would essentially never fill. The bid–ask spread on this
  illiquid name is routinely 1–2 ticks and widens when it actually trades. The buffer must clear
  tick + spread with margin to exit in a fast drop, so it is set to ~2 ticks (3.5% ≈ ₱0.021).
- PSE tick check: at ₱0.60 the PSE tick is ₱0.01 (₱0.50–4.99 band) ≈ 1.67%; the 3.5% buffer
  (₱0.021) ≈ 2 ticks, covering one tick + a typical 1-tick spread. ✔
- Rounding: `1.50% → ` **`3.5%`** (after tick/spread widening, rounded to nearest 0.25)
- **Limit Price = 3.5%**
